TITLE:
Plot Bridge

SHORT SUMMARY (one line):
Insert SymPy/Matplotlib plots at the cursor in Writer, Calc, Impress and Draw — 2D, parametric, polar, implicit and 3D surfaces.

DESCRIPTION:
Plot Bridge inserts high-quality mathematical plots directly at the cursor in
Writer, Calc, Impress and Draw. Choose a plot type, enter the function(s), set
ranges, grid and labels, and the plot is placed in your document. Plots are
re-editable: select an inserted plot and reopen the dialog to change anything —
including adding or removing a function — and it is replaced in place.

Plot types: 2D functions y=f(x), 2D parametric x(t) y(t), polar r(theta),
implicit F(x,y)=0, 3D surface z=f(x,y), 3D cylindrical z=f(r,theta), 3D
spherical r=f(theta,phi), and 3D parametric surface x,y,z(u,v). Includes an
Examples dropdown (up to 5 per type) that fills the fields, colormap selection
for 3D surfaces, and pi input in ranges (pi, 2pi, pi/2).

Supports multiple functions on one graph, automatic or manual X/Y ranges,
major/minor grid with optional manual step sizes, titles, axis labels and a
legend. Expressions use SymPy syntax with implicit multiplication (3sin(x), 2x)
and a wide function set (sin, cos, exp, log, sqrt, gamma, zeta, erf, besselj, …).

IMPORTANT — REQUIREMENTS:
Plotting runs in your system Python 3, which must have SymPy, NumPy and
Matplotlib installed:
    python3 -m pip install sympy numpy matplotlib
Works on Linux and Windows.
