TITLE:
Plot Bridge

SHORT SUMMARY (one line):
Insert SymPy/Matplotlib function plots at the cursor in Writer, Calc and Impress.

DESCRIPTION:
Plot Bridge inserts high-quality vector (SVG) mathematical plots directly at the
cursor in LibreOffice. Type one or more functions of x, set ranges, grid and
labels, and the plot is placed in your document. Plots are re-editable: select
an inserted plot and reopen the dialog to change anything — including adding or
removing a function — and it is replaced in place.

Supports multiple functions on one graph, automatic or manual X/Y ranges,
major/minor grid with optional manual step sizes, titles and axis labels, and a
legend. Expressions use SymPy syntax with implicit multiplication (3sin(x), 2x)
and a wide function set (sin, cos, exp, log, sqrt, gamma, zeta, erf, besselj, …).

IMPORTANT — REQUIREMENTS:
Plotting runs in your system Python 3, which must have SymPy, NumPy and
Matplotlib installed:
    python3 -m pip install sympy numpy matplotlib
Linux works out of the box. Windows/macOS need a system Python 3 with those
modules and the path configured. This is an early, Linux-first release.
